# Download

موقع تجريبي (Prototype) لتحميل الفيديوهات من منصات التواصل الاجتماعي — تيك توك، انستجرام، فيسبوك، بينتريست، سناب شات، يوتيوب وتويتر/X.

## الملفات
- `index.html` — بنية الصفحة
- `style.css` — كل التنسيقات والحركات (Animations)
- `script.js` — منطق الموقع (كشف المنصة، شاشة الترحيب، توليد وتنزيل الملف)

## تشغيل الموقع محليًا
افتح `index.html` مباشرة في المتصفح، أو ارفع الملفات الثلاثة على GitHub Pages:

1. أنشئ ريبو جديد وارفع الملفات الثلاثة (`index.html`, `style.css`, `script.js`) في الجذر.
2. من إعدادات الريبو (Settings → Pages) فعّل GitHub Pages على فرع `main`.
3. هيديك رابط مباشر للموقع شغّال أونلاين.

## ملاحظة مهمة
زرار التحميل حاليًا **بيولّد ملف تجريبي حقيقي** (صوت WAV أو فيديو WEBM) وينزّله فعليًا على الجهاز، عشان تجربة الاستخدام تبقى كاملة. لكن الموقع **مش متصل فعليًا** باستخراج فيديوهات حقيقية من تيك توك/انستجرام/يوتيوب — ده محتاج سيرفر خلفي (Backend) منفصل يتواصل مع كل منصة، وغير موجود في هذا الكود.

لو هتكمل المشروع فعليًا، خد بالك إن تنزيل محتوى من غير إذن أصحابه ممكن يخالف شروط استخدام المنصات وحقوق الملكية الفكرية.
